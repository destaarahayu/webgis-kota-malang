# WebGIS Kota Malang

WebGIS ini menampilkan persebaran fasilitas di Kota Malang yang diambil dari data OpenStreetMap.

## Fitur

- Menampilkan peta interaktif menggunakan Leaflet.js
- Visualisasi data dalam format GeoJSON
- Kategori fasilitas:

  - ATM
  - Bank
  - Cafe
  - Fast Food
  - Restaurant
- Legenda (keterangan simbol) berdasarkan kategori
- Statistik jumlah setiap kategori fasilitas

## Teknologi

- HTML, CSS, JavaScript
- Leaflet.js
- OpenStreetMap
